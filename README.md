# Web3 Security Journey

My learn-by-doing path to becoming a smart contract security researcher.

I document what I learn, what I break, and how I fix it.

## Why this repo exists

This repository is my public study log for learning smart contract security from the ground up. The goal is to build a strong understanding of blockchain fundamentals, Solidity, security patterns, and exploit reasoning before moving into CTFs, audits, and real-world bug hunting.

## Learning roadmap

- Blockchain fundamentals
- Ethereum and EVM basics
- Solidity and smart contract design
- Common vulnerability classes
- Exploit development and PoCs
- Reading public audit reports
- Practice through CTFs and challenge repos

## Write-up format

Every challenge or vulnerability note should answer these questions:

1. What does the contract do?
2. Where is the vulnerability?
3. How was it exploited?
4. How should it be fixed?

## Notes and learning workflow

- Read a concept or course section.
- Summarize the idea in my own words.
- Identify the key risks, trade-offs, and assumptions.
- Write a short note or PoC.
- Review the write-up for clarity and correctness.
