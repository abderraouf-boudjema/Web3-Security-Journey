# Section 1: What Is A Blockchain

Course: [Blockchain Basics](https://updraft.cyfrin.io/courses/blockchain-basics) (Cyfrin Updraft)

## What I learned

A blockchain is a shared record of transactions that is stored on many computers at the same time, instead of being held by one company or one bank. Transactions are grouped into blocks, and each block is linked to the one before it, which forms a chain. Because every participant keeps a copy, it is very hard for anyone to secretly change what was recorded earlier.

The main idea I took from this section is decentralization: nobody has to be trusted blindly, because the rules are enforced by the network itself and anyone can verify the record. This is also what makes smart contracts possible, since they are programs that live on the blockchain and run exactly as written, without needing an intermediary.

## Why this matters for security

Since code on a blockchain is public and usually cannot be changed after deployment, a mistake in a smart contract can be exploited by anyone and may be impossible to patch. This is why security researchers are needed.
