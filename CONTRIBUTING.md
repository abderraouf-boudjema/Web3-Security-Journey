# Contributing

Thanks for taking interest in this repository.

This project is primarily a personal learning repository for smart contract security, but feedback, corrections, and suggestions are welcome.

## How to contribute

1. Open an issue for ideas, questions, or mistakes.
2. Suggest improvements to notes or explanations.
3. Share a better explanation or a corrected understanding.
4. Submit a pull request for documentation improvements.

## Writing standards

- Prefer clear, plain-language explanations.
- Explain concepts in your own words when possible.
- Include the core idea, the risk, and the fix.
- Keep write-ups structured and readable.
- Use markdown headings and tables when useful.

## Repository conventions

- Put course notes in `courses/<course-name>/`.
- Put challenge write-ups in their own folder or repo section.
- Keep notes focused on learning and understanding.
- Use consistent naming for sections and files.

## Example structure

```text
courses/
  blockchain-basics/
    README.md
    section-1-what-is-a-blockchain.md

ethernaut/
  README.md
  level-00-hello-ethernaut/
```

## Be respectful

This is a learning space. Please keep feedback constructive and focused on improving understanding.
